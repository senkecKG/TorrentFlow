FAQ

Questions, answered.

Is torrenting legal? +

The BitTorrent protocol is legal and used for Linux distributions, game patches, scientific datasets and more. Downloading copyrighted content without permission is not legal in most countries. TorrentFlow is a tool — use it responsibly and respect copyright.

Does it really have no ads or telemetry? +

Correct. No ads, no bundled offers, no analytics, no network calls except torrent traffic. The source is MIT licensed, so you can verify every line.

How does streaming work? +

TorrentFlow fetches pieces in sequential order, prioritizes subtitle and header files, and serves the partial file locally. VLC plays it as soon as the buffer is deep enough. You watch while the rest downloads.

Will it use all my bandwidth? +

It behaves like any well-mannered client: DHT discovery is lightweight, and you stay in control. Speed limits and scheduling are on the roadmap.

macOS or Linux? +

Windows first — it is where the pain was worst. The codebase is portable (Tauri 2 + Rust), so other platforms are realistic once the Windows experience is perfect.
